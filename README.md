# Bee yourself

![Bee yourself](site/poster.jpg)

## Build

Requires macOS 26 and the Swift toolchain.

```
./scripts/bundle.sh
open "Bee yourself.app"
```

The browser version needs the Swift 6.3.2 toolchain from swift.org, its WebAssembly SDK and binaryen:

```
./scripts/web.sh
```
